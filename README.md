# BurjX KYC Onboarding State Machine

Frontend-only **Expo / React Native / TypeScript** multi-step KYC onboarding flow for a crypto exchange. No backend — all verification behavior is simulated as local async TypeScript.

```bash
npm install     # uses .npmrc → legacy-peer-deps=true
npm start       # Expo dev server
npm test        # one-command test suite
```
